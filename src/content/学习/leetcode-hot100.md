## 回溯

回溯大体上分为两种，第一种思路是选或者不选，这种做法不需要for循环；第二种思路是枚举起点，用for循环的做法实现。几种回溯题目的类型：

### 子集型回溯

lc17 电话号码字母组合；lc78 子集；lc131分割回文串

模板一（选或不选）：

```Python
def main(nums):
    n = len(nums)
    ans = []
    path = []
    def dfs(i):
        if i == n:
            ans.append(list(path))
            return
        # 不选 nums[i]
        dfs(i + 1)
        # 选 nums[i]
        path.append(nums[i])
        dfs(i + 1)
        path.pop()
    dfs(0)
    return ans
```

模板二（枚举选的位置）：

```Plain Text
def main(nums):
    n = len(nums)
    ans = []
    path = []
    def dfs(start):
        ans.append(list(path))  # 进来就收集
        for j in range(start, n):
            path.append(nums[j])
            dfs(j + 1)
            path.pop()
    dfs(0)
    return ans
```



### 组合型回溯

在求子集的基础上增加一个判断逻辑，可以通过剪枝优化（暂时先不记剪枝）

模板一（枚举选的位置）：

```Plain Text
class Solution:
    def combine(self, n: int, k: int) -> list[list[int]]:
        res = []
        path = []
        def dfs(i):
            # 收集条件：path长度等于k
            if len(path) == k:
                res.append(path.copy())
                return
            # 从start开始往后选，前面的不再选，避免重复
            for j in range(i, n + 1):
                path.append(j)
                dfs(j + 1)
                path.pop()
        dfs(1)
        return res
```



### 排列型回溯

lc46 全排列、lc78 N皇后

排列型回溯的不同点在于列表中的元素只能选择一次，所以需要通过建立一个新的列表来记录元素出现是否。

模板：

```Plain Text
class Solution:
    def permute(self, nums: list[int]) -> list[list[int]]:
        n = len(nums)
        res = []
        path = []
        used = [False] * n

        def dfs(i):
            if i == n:
                res.append(path.copy())
                return
            # 从头遍历全部元素
            for j in range(n):
                if not used[j]:
                    used[j] = True
                    path.append(nums[j])
                    dfs(i + 1)
                    path.pop()
                    used[j] = False
        dfs(0)
        return res
```

二编：

也可以不用初始化，直接从建立一个n \+ 2的列表，然后从i \+ 2开始计算dp，此时第n个对应的是n \+ 1。

```Python
class Solution:
    def rob(self, nums: List[int]) -> int:
        n = len(nums)
        dp = [0] * (n + 2)
        
        for i in range(n):
            dp[i + 2] = max(dp[i + 1], dp[i] + nums[i])

        return dp[n + 1]
```

## 哈希与双指针

核心套路：**用空间换时间，把"查找"从 O(n) 降到 O(1)**。

- 两数之和、字母异位词：一个 `Map` 就够，注意 key 的设计（排序后的字符串、计数数组）
- 三数之和：排序 + 固定一个数 + 双指针，重点是**去重逻辑**——跳过重复的锚点和重复的左右指针
- 盛最多水的容器：左右指针向中间收，每次移动较小的一边（移动较大的一边不可能变优）

```python
# 三数之和的去重是易错点
nums.sort()
for i in range(len(nums) - 2):
    if i > 0 and nums[i] == nums[i-1]:  # 锚点去重
        continue
    l, r = i + 1, len(nums) - 1
    while l < r:
        s = nums[i] + nums[l] + nums[r]
        if s == 0:
            res.append([nums[i], nums[l], nums[r]])
            while l < r and nums[l] == nums[l+1]: l += 1  # 左指针去重
            while l < r and nums[r] == nums[r-1]: r -= 1  # 右指针去重
            l += 1; r -= 1
        elif s < 0: l += 1
        else: r -= 1
```

## 滑动窗口

模板只有一套：右指针扩张，条件满足时左指针收缩。难在"条件"怎么维护：

- 无重复字符最长子串：用 `Map<字符, 下标>`，遇重复直接跳左指针到上次出现位置的下一格
- 找到字符串中所有字母异位词：定长窗口 + 计数数组，比较两个 26 长度数组是否相等
- 最小覆盖子串：`need` 和 `window` 两个计数器，`valid` 记录已满足的字符种数

## 链表

口诀：**画图、虚拟头节点、快慢指针**。

- 反转链表：`prev/cur/nxt` 三指针，写熟到肌肉记忆
- 环形链表 II：快慢指针相遇后，一个指针回头，同速前进再相遇即入口（数学推导要能口述）
- 合并 K 个升序链表：最小堆（`heapq`）O(N log K)，或者分治两两合并
- LRU 缓存：哈希表 + 双向链表，这是**面试高频手撕题**，建议单独练到 15 分钟内写完

## 二叉树

遍历是地基，递归要能秒写，再补一个迭代版（栈模拟）。高频套路：

- 层序遍历：队列 + 按层弹出，衍生出右视图、之字形、最大深度
- 最近公共祖先：后序递归，左右子树分别找，两边都非空则当前节点是答案
- 路径总和、二叉树展开为链表：递归改树结构时，先用临时变量保存左右子树再操作
- 验证二叉搜索树：不是只比较父子节点，要传上下界，或者用中序遍历严格递增

## 动态规划

Hot 100 里的 DP 大多不难，难的是识别状态定义：

- 爬楼梯 / 打家劫舍：一维，`dp[i]` 只依赖前两项
- 最大子数组和：`dp[i] = max(nums[i], dp[i-1] + nums[i])`，注意答案是 `max(dp)` 不是 `dp[-1]`
- 完全平方数 / 零钱兑换：完全背包，外层物品内层容量，求最小值时初始化为无穷大
- 最长递增子序列：O(n²) 的 DP 必须会写，O(n log n) 的贪心 + 二分是加分项
- 编辑距离：二维 DP，画表格理解"增删改"三个转移来源，面试常考口述

## 回溯

模板：**路径 + 选择列表 + 撤销**。Hot 100 里的回溯集中在排列组合、子集、N 皇后。

```python
def backtrack(路径, 选择列表):
    if 满足结束条件:
        result.append(路径[:])  # 注意拷贝！
        return
    for 选择 in 选择列表:
        剪枝条件检查
        做选择
        backtrack(路径, 新选择列表)
        撤销选择
```

全排列的去重（`used` 数组）、子集的 startIndex 控制是两个高频易错点。

## 面试结合

3. **报时间空间复杂度**，写完主动过一遍测试用例

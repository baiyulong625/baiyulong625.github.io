你现在看到的这篇文章，就是一个 Markdown 文件。它没有数据库，没有后台编辑器，只是一段带格式标记的纯文本。

## 为什么是纯文本

纯文本最大的好处是**长寿**。十几年后 Word 文件可能打不开，但 `.md` 文件永远可以。它不依赖某个软件、某个平台，任何编辑器都能编辑。

## 我的工作流

1. 在任意编辑器里新建 `.md` 文件
2. 顶部写一段 frontmatter（标题、日期、分类）
3. 用简洁的 Markdown 语法写正文
4. 保存后运行构建，网站自动生成文章页

## 搭配版本控制

把 Markdown 放进 Git 仓库，就有了免费的历史记录。每次修改都留痕，写错了可以随时回退。配合 GitHub，发布只是 `git push` 一下的事。

工具越简单，越能专注于写作本身。
